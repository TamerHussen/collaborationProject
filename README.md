# Group 4 : Think Tank Touchscreen Interactive Experience​

A touchscreen Interactive experience to explore some of the ThinkTank vehicles, by using puzzle pieces to create each model.

* Touchscreen​


## How to Open the Project

1. Download the project folder on your computer.
2. Extract the folder onto your computer.
3. Navigate to the `build` folder.
4. Open the `build` folder with your preferred editor or environment to view or run the project.
